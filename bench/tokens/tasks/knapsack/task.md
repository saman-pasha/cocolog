# Knapsack

The first line of the input holds two numbers, N and W. Each of the next N
lines holds an item's weight and value, both positive integers. N is at most
50 and W is at most 10000.

Choose some of the items, each at most once, whose weights add up to at most
W and whose values add up to as much as possible, and print that largest
total value (0 if no item fits).

Example input:

```text
3 50
10 60
20 100
30 120
```

Example output:

```text
220
```
